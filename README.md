# Hands On Design Command Centre — interactive demo

A working demo of a project-management and ERP system for Hands On Design (architecture, interiors and turnkey execution).

**Open the demo:** https://khuranagurdeep-sys.github.io/hod-command-centre/

- Six interfaces: Owner, Project Manager, Designer/office, Site supervisor app, Client portal, Contractor portal
- Pick a role on the sign-in page (no email or password needed), then use **Demo scenarios** for guided walkthroughs
- All projects, people (other than the founder), contractors, clients and amounts are fictional sample data
- Changes are saved in the viewer's browser only; Settings → Demo data resets them

Company name, address, contact details and logo are from handsondesign.in and its company presentation.
